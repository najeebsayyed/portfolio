Welcome to the official repository for **Najeeb Sayyed's Portfolio Website** — a premium, Awwwards-inspired developer portfolio designed for **Mobile App Developers** specializing in React Native, Expo, TypeScript, and Generative AI integration.

---

## 🌟 Key Features

- **⚡ Interactive AI Terminal Sandbox**: A interactive Zsh-style developer console with live commands (`whoami`, `skills`, `projects`, `experience`, `contact`).
- **📱 Mobile-First & Responsive Design**: Crafted with Tailwind CSS v4 and Framer Motion for 60fps animations across mobile, tablet, and desktop.
- **🎨 Glassmorphism & Modern Dark UI**: Dynamic glowing ambient blobs, custom spotlight hover effects, and crisp typography using Inter, Space Grotesk, and JetBrains Mono.
- **🚀 Multi-Category Projects Showcase**: Filter projects across `Mobile Apps`, `AI Powered`, and `Websites` with embedded video modal demos.
- **🛠 Interactive Skill Arsenal**: Categorized brand-icon grid covering Languages, Mobile, Frontend, Backend & DB, AI/ML, and Dev Tools.
- **📬 Functional Contact System**: Seamless inquiry submission via Formspree.

## 💻 Getting Started Locally

Prerequisites: Node.js (v18+) and `npm` or `pnpm`.

```bash
# 1. Clone the repository
git clone https://github.com/najeebsayyed/portfolio.git

# 2. Navigate to project folder
cd portfolio

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

Open `http://localhost:5173` in your browser.

### 🏗 Production Build

To build the production bundle:

```bash
npm run build
```
